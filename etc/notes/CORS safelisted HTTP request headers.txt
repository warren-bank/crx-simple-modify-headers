How to set CORS safelisted HTTP request headers
without triggering a CORS preflight request...

--------------------------------------------------------------------------------

no preflight:
=============

fetch('https://www.youtube.com/watch?v=qhKci8jY510', {headers: {"content-language": "SMH;Aa0-*=Aa0-*,SMH;Bb1-*=Bb1-*"}})
.then(res => res.json())
.then(console.log)

fetch('https://www.youtube.com/watch?v=qhKci8jY510', {headers: {"accept": "SMH/Aa0-*=Aa0-*,SMH/Bb1-*=Bb1-*"}})
.then(res => res.json())
.then(console.log)
